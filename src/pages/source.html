Build from source

You need JDK 17, the Android SDK (platform 36) and the Gradle wrapper that is already in the repository.

git clone {{cloneUrl}}
cd nexguard
chmod +x ./gradlew
./gradlew test lint assembleRelease

A signed release also needs KEYSTORE_PATH, KEYSTORE_PASSWORD, KEY_ALIAS and KEY_PASSWORD as environment variables. Never commit a keystore.
