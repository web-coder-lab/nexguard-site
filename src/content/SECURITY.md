# Security policy

## Supported versions

| Version | Supported |
|---|---|
| 1.0.3 | Yes |

## Reporting a vulnerability

Email dickvoice734@gmail.com with a clear description, affected version, and steps to reproduce.

Do not open a public issue for a vulnerability until a fix is available.

NEXGUARD stores notification history only on the device. Reports should not include another person's private notification content.
